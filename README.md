# Black Friday Sales Analysis

### SQL Project Showcase

This project presents an Exploratory Data Analysis (EDA) of a Black Friday Sales dataset using SQL on 100,000 transaction records. The analysis focuses on customer purchasing behavior, top-performing product categories, discount impact on sales, customer segment performance, and peak shopping patterns to generate business insights.

---

## Project Overview

The project was developed using MySQL and SQL queries to perform:

- Data Understanding
- Data Cleaning
- Exploratory Data Analysis (EDA)

The objective of this project is to explore transactional retail data and identify key business insights during the Black Friday sales period.

### 2. Data Cleaning
- Fix incorrect data types

### 3. Exploratory Data Analysis (EDA)
- Revenue by product category
- Revenue contribution analysis
- Discount impact on spending behavior
- Customer segment analysis
- Peak shopping hour analysis

---

## Key Insights

- Electronics generated the highest revenue during Black Friday.
- Returning customers contributed the most revenue.
- Moderate discounts performed better than extremely high discounts.
- Peak shopping activity occurred between 22:00 to 21.00.
